# 鑫汇盈股票看板

一个面向 A 股的轻量持仓看板，包含智能话术生成器、多自选组合、股票代码与名称自动匹配、实时行情及当日涨幅展示。

## 主要功能

- 输入股票名称或 6 位代码自动匹配证券
- 根据公司主营业务与产业方向生成一句话逻辑
- 一键加入已有组合，或新建自选组合
- 同一股票可在不同组合中设置不同成本价
- 展示现价、持仓收益与当日涨幅
- 数据保存在当前浏览器本地，无需注册登录

## 本地运行

需要 Node.js 22.13 或更高版本，以及 pnpm。

```bash
pnpm install
pnpm dev
```

## 构建与发布

```bash
pnpm build
pnpm deploy
```

生产环境运行于 Cloudflare Workers。配置见 [`wrangler.jsonc`](./wrangler.jsonc)。

## 数据说明

行情、证券搜索和公司资料来自公开行情接口，可能存在延迟或临时不可用。页面生成内容仅用于信息整理，不构成任何投资建议。
